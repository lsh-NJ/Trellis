# Trellis 演示脚本（2026-11-08）

> 用途：参赛线上评审的视频录制与现场讲解共用稿。
> 设计原则：**一条主线讲完一个闭环**——用户给一个真实目标 → AGENT 调研并产出大纲 → 阶段/周/日逐层落地 → 学习与实践分开 → 完成后有练习 → 没做完管家自动重排 → 周末有复盘。
> 时长：主片 3–5 分钟；另有 90 秒速览版（第 6 节）与 8 分钟答辩版（第 7 节）。

---

## 0. 录前准备

**数据目录**（绝不提交、录完即删）：

```bash
rm -rf /tmp/trellis-demo
mkdir -p /tmp/trellis-demo
cp ~/.trellis/llm.json ~/.trellis/study.json /tmp/trellis-demo/
```

> 用干净 home 起演示，避免历史测试计划、会话、报错记录入镜。
> 如果要展示「已有历史」的观感，可先按第 2 节跑一遍流程，再回到录屏。

**启动**（源码运行，当前功能都在 main 上）：

```bash
cd /Users/ahs/Trellis
export JAVA_HOME=/Users/ahs/Trellis/.toolchain/jdk-17.0.21+9/Contents/Home
TRELLIS_HOME=/tmp/trellis-demo TRELLIS_DEV=1 /Users/ahs/Trellis/app/desktop/build/compose/binaries/main/app/Trellis.app/Contents/MacOS/Trellis
```

若用 `./gradlew :app:desktop:run`，注意先关掉旧实例，且运行期间不要编译。

**窗口与外观**：窗口 1180×820（或 1440×900 以展示右侧「阶段进度」栏）；深色主题；字号标准。

**演示日期（重要）**：排周按「今天到周日」的剩余容量算，录制当天若是周日，第一周只剩 1 天，计划页会显得很空（行为正确但不好看）。两种处理：工作日录制（最自然）；或把演示 home 的应用内今天拨到周一：`TRELLIS_TODAY=2026-11-09 TRELLIS_HOME=/tmp/trellis-demo`（只对非默认 home 生效），计划页顶部会出现浅色「模拟时间」提示条，录制时裁掉或改真实工作日录。

**录制**：1920×1080 / 30fps，只截应用窗口；输入等待一律剪掉（或 2× 快进）；字幕标出关键动作。

## 1. 主线分镜（约 4 分钟）

### 镜头 1｜问题：你缺的不是课程，是一条走得完的路线（0:00–0:25）

- 画面：对话页空态（不出现任何调试/报错内容）。
- 讲词：
  > 「网上不缺课。缺的是——这门课学哪几段、每周花多少、哪一天做什么、做完怎么算学会。Trellis 从一个目标开始，把这些全部排出来。」

- 动作：不点任何东西，直接开始打字。

### 镜头 2｜一句话目标 → AGENT 调研（0:25–1:20）

- 输入（直接粘贴，避免拼音卡顿）：

  > 我想成为 AI 应用工程师，四个月内能独立做出 RAG 应用。请先调研，再给我一份学习计划大纲。

- 关键画面：
  1. 过程行依次出现：搜索资料 → 抓取正文 → 记了一步（可停留 2 秒，配讲词「它先去查，再规划」）。
  2. 回复出现：阶段大纲（第一阶段 / 第二阶段 / 第三阶段）、每天时长建议、目标「成为 AI 应用工程师」。
  3. 若弹出「选一个」：点「每天 2 小时」——讲词「时长我自己拍板，它只给建议」。
  4. 回复末尾说明：计划已建、本周已排、计划文档已写好。

- 讲词：
  > 「它没有直接丢给我一堆视频，而是先查资料、再拆阶段：第一阶段搞清楚 RAG 是什么、跑通最小检索；第二阶段搭系统；第三阶段做项目。每个阶段的目标和跨度都写在大纲里。」

### 镜头 3｜计划页：阶段 · 周 · 天（1:20–2:10）

- 动作：左栏点「计划」，切到这份新计划。
- 关键画面（从上到下依次停留）：
  1. 页头「目标 · 1」「计划文档」，宽屏时右侧出现「阶段进度」（第一阶段 1/17）。
  2. 阶段条三个 chip：点第二阶段的 chip → 跳到该阶段第一周（讲词「阶段不是装饰，可以直接跳」）。
  3. 周刻度条：拖/点周刻度，切周。
  4. 每天是一行折叠：展开今天 → 节点带方形勾选框、像素进度、类型后缀「· 学习 / · 实践」。
  5. 点节点标题 → 展开「学习资源」：B 站具体的某一集（第 N 集），点链接会用浏览器打开（可只展示不点）。
- 幂等演示（先切回会话发一句，再回计划页）：
  - 管家会话发「排一下本周的每日安排」；它会回「2026-W45 这一周已经排过了（2 条）；要调整就直接在计划页拖节点…」——**不会**再追加一批单元、也不会把当天堆到 100 多分钟。
  - 回计划页：切到第 2 周，每天 1 件、单日不超过每天预算；排不下的条目留在「待安排」池（抽屉里能看到明细）。
  - 讲词：「周计划不是一次排到底：它按每天能投入的量，一天一天铺；这一周放不下的，进待安排池等下周，不会堆在某一天。已经排过的周再问一次也不会重复排——所以它不会越用越乱。」
- 讲词：
  > 「周不再是七个大方框，而是刻度；每天默认折叠，展开就是当天要做的几件事。每个节点都能点开看到对应的学习资源——不是把课程目录原样搬过来，片尾、预告这类东西在导入时就被洗掉了。」

### 镜头 4｜执行与练习闭环（2:10–2:50）

- 动作：
  1. 勾掉 1–2 个节点，像素条亮起（讲词「完成进度不是一个百分比，是一格一格亮起来」）。
  2. 勾完一个节点 → 管家会话弹「练习建议」卡（题库匹配到的一道题）。
  3. 点「开始练习」→ 二级页只显示这一道题 → 看答案 → 「记住了 / 没记住」（或选择题直接判对错）。
- 讲词：
  > 「学完一个单元，它会从题库里挑一道匹配的题；只显示这一道，做完就回会话。答题记录会变成掌握度——下次优先给你没做过的、做错过的题。」

### 镜头 5｜没做完怎么办：管家自动重排（2:50–3:20）

- 动作：把窗口切到后台几秒再切回（或直接在设置里打开/保持自动采纳开），让管家在「应用不在前台」时自动采纳建议。
- 关键画面：管家会话里出现「—— 已把 N 件没做完的挪到之后几天（应用不在前台，已自动重排）」，计划页对应节点换到新日期。
- 讲词：
  > 「计划被打断是常态。它在后台把逾期节点自动挪到之后几天，而且可回看、可拖回去。自动做的事一定要能被看见、能被撤销。」

### 镜头 6｜周复盘（3:20–3:45）

- 动作：把日期调到本周日（设置 → 时间调试），计划页底部点「生成本周总结」。
- 关键画面：周复盘卡出现叙述与统计（完成单元 / 投入分钟数）。
- 讲词：
  > 「周日不用等周一，这一周做了多少、哪几天断了，当场生成复盘。下一周的计划从这里开始。」

### 镜头 7｜收束：知识库与计划文档（3:45–4:10）

- 动作：导航「知识库」→「计划文档」，展示只读的大纲与每周文档（左栏「计划文档」列表统一为对话页样式）。
- 讲词：
  > 「计划文档不是普通笔记，不会被概念抽取或自动完成污染；它只在这里看，要改跟 AGENT 说。所有东西都在本地，换台电脑拷一个目录就走。」

- 结束画面：回到计划页全景（阶段条 + 周刻度 + 当天列表 + 右侧阶段进度），停顿 1 秒。

## 2. 为了录这一条，先预跑一遍（不在镜头里）

```bash
# 1) 按镜头 2 建计划（真实网络调用，约 40–90 秒）
# 2) 在计划页勾掉 2–3 个节点，让像素进度有内容
# 3) 设置 → 时间调试：日期改到本周日 → 计划页点「生成本周总结」
# 4) 打开一次知识库→计划文档，确认大纲与周文档都在
# 5) 回设置把日期改回今天，重新录屏
```

检查清单：

- [ ] 左栏有「学习计划」且目标计划在列（不要出现空计划页）
- [ ] 阶段条 3 个 chip 的内容完整（名字 + done/total）
- [ ] 今天有节点；至少一个节点带「资源 1」
- [ ] 有「计划文档」且能打开总览与至少一周
- [ ] 每轮输入都显示成完整中文（没有拼音串/英文候选）
- [ ] 没有「AI 没配置」、没有调试日志、没有测试会话名

## 3. 输入文案（直接复制，避免输入法问题）

1. 建计划：`我想成为 AI 应用工程师，四个月内能独立做出 RAG 应用。请先调研，再给我一份学习计划大纲。`
2. 选时长（若弹选项）：「每天 2 小时」。
3. （可选）幂等演示：再发一次 `排一下本周的每日安排` —— 会回复「这一周已经排过了」，不重复排；这是有意设计，别当成 bug。
4. （可选）问下一步：`下周的重点是什么？`
5. （可选）练习后：`根据我的掌握度，接下来多练哪一块？`

## 4. 兜底镜头（网络/模型不稳定时用）

- 大纲与周文档：直接打开「知识库 → 计划文档」展示已生成内容（不需要现场等模型）。

- 阶段跳转、资源展开、像素进度、放弃计划：都可离线展示，不依赖网络。

## 5. 讲解口径（别踩的坑）

- ❌ 「全自动 AI 学习」→ ✅ 「AGENT 负责推进，决定权在你：时长你拍板、计划可拖、自动动作可回看可撤销」。
- ❌ 「用了 DeepSeek 的模型/搜索」当卖点 → ✅ 讲「调研是搜索+抓取+结构化」，模型只是其中一个环节。
- ❌ 「学习效果提升」类效果承诺 → ✅ 只讲「完成度、掌握度、计划可持续」这些能看见的指标。
- ❌ 不展示未完成/半成品页面（旧打包版、移动端、插件市场）。
- 数据口径以 `pitch/demo-pitch.md` §6 为准；本轮新增能力需更新数字（阶段/资源/放弃/四周自动排周/计划文档只读区/网络调研）。
- ❌ 「它一次把几十周都排进日历」→ ✅ 「先定阶段和大纲，每周按**每天预算**滚动排；本周剩余容量不够的条目留在待安排池，不硬塞某一天」。周文档末尾会写「本周还剩 N 条排在待安排池」，现场可指。
- ❌ 「大纲就是一堆章节名」→ ✅ 每个阶段都有「交付物 + 过关标准」（可验收），点开计划文档能看到。
- ❌ 「再排一次本周会更好/更全」→ ✅ 「一周只排一次：已排过的周会直接退回，要改就在计划页拖节点，或告诉它把哪几条改到哪天」。已排过的周不会重复追加单元（旧版本曾把同一周越排越多）。
- ❌ 说「AI 自动帮你勾完成」时又不演示撤销 → ✅ 演示 `AI 自动完成` 卡的「撤销」（会改回待做并写屏蔽）。

## 6. 90 秒速览版（评审预览用）

1. 0–10s：一句话目标 + 过程行「搜索资料 → 抓取正文」。
2. 10–25s：三个阶段大纲 + 每天时长建议 + 「每天 2 小时」选择。
3. 25–45s：计划页阶段条点击跳阶段 + 周刻度 + 展开今天 + 像素进度。
4. 45–60s：点节点看资源 → 勾掉一个 → 练习建议卡 → 单题作答。
5. 60–75s：管家自动重排的状态行 + 计划节点换日。
6. 75–90s：周复盘叙述 + 计划文档只读页 → 收束一句话。

## 7. 8 分钟答辩版增补

- 3 分钟主线同第 1 节，之后补：
  - 架构一页：内核 / 计划后端（事件溯源）/ AI 层 / 插件三轨（讲解 1 分钟）。
  - 数据与可靠性：本地 SQLite、事件可追溯、撤销、删除范围可控（清除数据）、安卓共享代码约束（1 分钟）。
  - 评测与局限：题库规模、掌握度是启发式、没有云端同步、移动端未落地（1 分钟）。
  - 后续路线：目标/能力地图、语义记忆、题源扩展（1 分钟）。
