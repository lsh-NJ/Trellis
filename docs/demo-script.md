# Trellis 演示脚本（2026-11-08）

> 用途：参赛线上评审的视频录制与现场讲解共用稿。
> 设计原则：**一条主线讲完一个闭环**——用户给一个真实目标 → AGENT 调研并产出大纲 → 阶段/周/日逐层落地 → 学习与实践分开 → 完成后有练习 → 没做完管家自动重排 → 周末有复盘。
> 时长：主片 3–5 分钟；另有 90 秒速览版（第 6 节）与 8 分钟答辩版（第 7 节）。

---

## 0. 录前准备

**数据目录**（绝不提交、录完即删）：

```bash
rm -rf /tmp/trellis-demo
mkdir -p /tmp/trellis-demo
cp ~/.trellis/llm.json ~/.trellis/study.json /tmp/trellis-demo/
mkdir -p /tmp/trellis-demo/exams
cp demo/exams/*.jsonl /tmp/trellis-demo/exams/   # 演示用 AI/RAG 题库（练习提议要匹配它，见镜头 4）
```
> 主题：默认「跟随系统」，白天会随日出从深色翻成浅色。录前在设置里固定成深色，别让镜头中途变色。

> 用干净 home 起演示，避免历史测试计划、会话、报错记录入镜。
> 如果要展示「已有历史」的观感，可先按第 2 节跑一遍流程，再回到录屏。

**两条自主链（§8）的预置数据**：自主检查只在「阶段真正走完 / 计划真正做完」那一刻触发，所以演示 home 里必须是**已经接近完成**的数据，不能现场从零攒：

- 通识计划：阶段 1 只差最后 1 个节点（其余节点先勾掉），计划里还有后续阶段——用来演「阶段完成 → 推练习」。
- 就业向计划 + 目标：只有一个阶段、只差最后 1 个节点，且**待安排池为空**（`planDone` 要求它空）；用 `link_plan_to_goal` 挂到一个目标上，目标里至少 2 个里程碑——用来演「计划完成 → 由点到面」。
- 2–3 篇知识笔记（概念已抽取，至少 1 篇和就业方向相关），用来证明「这些我已经会了，别再安排一遍」。
- `<home>/exams/*.jsonl`（上面已 cp）与可用的 LLM key / 网络——自主轮要调 `search_web`、`recommend_exercises`。

做法：先在 `/tmp/trellis-demo-seed` 里把上面几项建好、勾到位、完整跑通一次，再把整个目录拷到 `/tmp/trellis-demo`；**不要在现场慢慢勾节点**。每条链录完就从 seed 重新拷一份 home——触发是一次性事件，勾过的数据不能复用第二次。

**启动**（源码运行，当前功能都在 main 上）：

```bash
cd /Users/ahs/Trellis
export JAVA_HOME=/Users/ahs/Trellis/.toolchain/jdk-17.0.21+9/Contents/Home
TRELLIS_HOME=/tmp/trellis-demo TRELLIS_DEV=1 TRELLIS_HIDE_SIM_BANNER=1 ./gradlew :app:desktop:run
```

注意：先关掉旧实例；运行期间不要编译（Gradle 会重写 classpath 里的文件，正在跑的窗口可能报 `NoClassDefFoundError`）。
（打包好的 `Trellis.app` 只有在 `./gradlew :app:desktop:packageDmg` 之后才是最新代码；录演示一律用上面的源码运行命令。）

**窗口与外观**：窗口 1180×820（或 1440×900 以展示右侧「阶段进度」栏）；深色主题；字号标准。

**演示日期（重要）**：排周按「今天到周日」的剩余容量算，录制当天若是周日，第一周只剩 1 天，计划页会显得很空（行为正确但不好看）。两种处理：工作日录制（最自然）；或把演示 home 的应用内今天拨到周一：`TRELLIS_TODAY=2026-11-10 TRELLIS_HOME=/tmp/trellis-demo`（只对非默认 home 生效）。加 `TRELLIS_HIDE_SIM_BANNER=1` 可以把「模拟时间」提示条藏掉（只有 `TRELLIS_DEV=1` 的调试场景才有这条横幅，正常用户看不到）。

**录制**：1920×1080 / 30fps，只截应用窗口；输入等待一律剪掉（或 2× 快进）；字幕标出关键动作。

## 1. 主线分镜（约 4 分钟）

### 镜头 1｜问题：你缺的不是课程，是一条走得完的路线（0:00–0:25）

- 画面：对话页空态（不出现任何调试/报错内容）。
- 讲词：
  > 「网上不缺课。缺的是——这门课学哪几段、每周花多少、哪一天做什么、做完怎么算学会。Trellis 从一个目标开始，把这些全部排出来。」

- 动作：不点任何东西，直接开始打字。

### 镜头 2｜一句话目标 → AGENT 调研（0:25–1:20）

- 输入（直接粘贴，避免拼音卡顿）：

  > 我想成为 AI 应用工程师，四个月内能独立做出 RAG 应用。请先调研，再给我一份学习计划大纲。

- 关键画面：
  1. 过程行会逐步显示它在调什么工具（「· 搜了资料」「· 抓了正文」「· 建了学习计划」），中间还会出现「思考 · …」——那是模型自己的 reasoning_content（不是宿主猜的），展开过程行能看到它当时在想什么。**可以点开其中一步的 ▾**：会看到这个工具的说明、完整参数、返回结果——讲词「过程不藏着：调了什么工具、传了什么参数、拿回什么，都能点开看」。有「格式不对，让它重说」的重试行，剪掉或别展开。
     若第一轮调研报「没解析成阶段表」，把同一句话再发一次（会自愈），这段剪掉。
  2. 回复出现：阶段大纲（现场通常 5–7 个阶段，别念死数量）。**问不问每天投入、排不排本周都由它自己判断**：可能先问一句，也可能直接按建议值把本周排出来。
  3. 如果它问了「选一个」：点「每天 120 分钟」——讲词「节奏我自己拍板，它不替我定死」。
  4. 它决定现在排时，同一轮就会把本周铺出来，回复里是「第一周（2026-Wxx）排好了…」；没排的话，下一句说「排本周」也一样。这里再给它 1 秒，让过程行自己把「排了本周」写出来。
  5. 「空壳 + 大纲」「计划文档」这些细节在计划页「计划文档」里看，会话里不一定逐字出现——讲词别照着工具结果念。

- 讲词：
  > 「它没有直接丢给我一堆视频，而是先查资料、再拆阶段：先搞清楚 RAG 是什么、跑通最小检索，再搭系统、做项目。每个阶段都写了交付物和过关标准——不是「了解一下」这种空话。」

### 镜头 3｜计划页：阶段 · 周 · 天（1:20–2:10）

- 动作：左栏点「计划」，切到这份新计划。
- 关键画面（从上到下依次停留）：
  1. 页头「目标 · 1」「计划文档」，宽屏时右侧出现「阶段进度」（第一阶段 1/17）。
  2. 右侧「阶段进度」栏（窗口 ≥1100dp 才出现）：每行一个阶段，名字 + 进度（没单元的阶段显示周区间 `W48–W51`）；点一行会跳到该阶段第一周（演示阶段 2–6 还没有单元时会回退到最后一张周卡——**这场不点阶段行**，只展示右栏进度）。顶部阶段条已删，别再找它。
  3. 周刻度条：当前只显示「已排到的本周 / 第 2 周」，后面的周按节奏滚动生成；完整 20 周在大纲与计划文档里——别说「全部已排好」。
  4. 每天是一行折叠：展开今天 → 节点带方形勾选框、像素进度、类型后缀「· 学习 / · 实践」。
  5. （可选）点节点标题看节点详情。研究路径暂时没有分集资源；B 站导入的计划才有「学习资源」，这段别硬录。
- 幂等演示（先切回会话发一句，再回计划页）：
  - 管家会话发「排一下本周的每日安排」；它会回「2026-Wxx 这一周已经排过了（N 条）；要调整就直接在计划页拖节点…」——**不会**再追加一批单元、也不会把当天堆到 100 多分钟。（周号与 N 以现场为准，别念死数字。）
  - 回计划页：切到第 2 周看每天 1–4 件、总量大致按每天预算（个别天会略超 1 条）；排不下的条目留在「待安排」池（重排抽屉能看到明细）。别在旁白里承诺「每天正好 N 分钟」。
  - 讲词：「周计划不是一次排到底：它按每天能投入的量，一天一天铺；这一周放不下的，进待安排池等下周，不会堆在某一天。已经排过的周再问一次也不会重复排——所以它不会越用越乱。」
- 讲词：
  > 「周不再是七个大方框，而是刻度；每天默认折叠，展开就是当天要做的几件事。阶段、周、天是三层：阶段回答「现在走到哪」，周回答「这一周做什么」，天回答「今天做什么」。」

### 镜头 4｜执行与练习闭环（2:10–2:50）

- 动作：
  1. 勾掉 1–2 个节点，像素条亮起（讲词「完成进度不是一个百分比，是一格一格亮起来」）。
  2. 勾完一个节点 → 管家会话弹「练习建议」卡（题库匹配到的一道题。前提：启动前把 `demo/exams/*.jsonl` 拷进演示 home 的 `exams/`，见 §0；否则种子题库只有 5 个非 AI 学科，匹配不到）。
     （这条是「单个节点完成」的旧链；「跨过一个阶段才触发」的自主链是另一条，见 §8.1，两者不冲突。）
  3. 点「开始练习」→ 二级页只显示这一道题 → 看答案 → 「记住了 / 没记住」（或选择题直接判对错）。
- 讲词：
  > 「学完一个单元，它会从题库里挑一道匹配的题；只显示这一道，做完就回会话。答题记录会变成掌握度——下次优先给你没做过的、做错过的题。」

### 镜头 5｜没做完怎么办：管家自动重排（2:50–3:20）

- 动作：把窗口切到后台几秒再切回（或直接在设置里打开/保持自动采纳开），让管家在「应用不在前台」时自动采纳建议。
- 关键画面：管家会话出现建议卡 +「已采纳」+ 一行变更（「跑通第一次API调用 挪到 11-13」）；计划页对应节点换到新日期。
  （「—— 已自动重排」那行目前只落数据不显示文本，别照着念；展示卡片 + 节点换日就够。）
- 讲词：
  > 「计划被打断是常态。它在后台把逾期节点自动挪到之后几天，而且可回看、可拖回去。自动做的事一定要能被看见、能被撤销。」

### 镜头 6｜周复盘（3:20–3:45）

- 动作（推荐预先做）：录屏前先把应用内日期拨到本周日、点一次「生成本周总结」，再把日期拨回；录屏时只回到计划页展示周四已生成的复盘卡。
  若要现场生成：设置 → 时间调试 → 改日期 → 计划页底部「生成本周总结」。（画面会短暂露出调试界面，录制时裁掉或快进。）
- 关键画面：周复盘卡出现叙述与统计（完成单元 / 投入分钟数）。
- 讲词：
  > 「周日不用等周一，这一周做了多少、哪几天断了，当场生成复盘。下一周的计划从这里开始。」

### 镜头 7｜收束：知识库与计划文档（3:45–4:10）

- 动作：计划页页头点「计划文档」，展示只读的大纲与每周文档（左栏「计划文档」列表统一为对话页样式）。
  （「知识库」首屏目前没有计划文档入口，别按旧稿走。）
- 讲词：
  > 「计划文档不是普通笔记，不会被概念抽取或自动完成污染；它只在这里看，要改跟 AGENT 说。所有东西都在本地，换台电脑拷一个目录就走。」

- 结束画面：回到计划页全景（周刻度 + 当天列表 + 右侧阶段进度），停顿 1 秒。

## 2. 为了录这一条，先预跑一遍（不在镜头里）

```bash
# 1) 按镜头 2 建计划（真实网络调用，约 40–90 秒）
# 2) 在计划页勾掉 2–3 个节点，让像素进度有内容
# 3) 设置 → 时间调试：日期改到本周日 → 计划页点「生成本周总结」
# 4) 打开一次知识库→计划文档，确认大纲与周文档都在
# 5) 回设置把日期改回今天，重新录屏
```

检查清单：

- [ ] 左栏有「学习计划」且目标计划在列（不要出现空计划页）
- [ ] 右侧「阶段进度」栏可见（名字 + 进度完整；窄窗口可放大窗口）
- [ ] 今天有节点；至少一个节点带「资源 1」
- [ ] 有「计划文档」且能打开总览与至少一周
- [ ] 每轮输入都显示成完整中文（没有拼音串/英文候选）
- [ ] 没有「AI 没配置」、没有调试日志、没有测试会话名

## 5. 讲解口径（别踩的坑）

- ❌ 「全自动 AI 学习」→ ✅ 「AGENT 负责推进，决定权在你：时长你拍板、计划可拖、自动动作可回看可撤销」。
- ❌ 「用了 DeepSeek 的模型/搜索」当卖点 → ✅ 讲「调研是搜索+抓取+结构化」，模型只是其中一个环节。
- ❌ 「学习效果提升」类效果承诺 → ✅ 只讲「完成度、掌握度、计划可持续」这些能看见的指标。
- ❌ 不展示未完成/半成品页面（旧打包版、移动端、插件市场）。
- 数据口径以 `pitch/demo-pitch.md` §6 为准；本轮新增能力需更新数字（阶段/资源/放弃/四周自动排周/计划文档只读区/网络调研）。
- ❌ 「它一次把几十周都排进日历」→ ✅ 「先定阶段和大纲，每周按**每天预算**滚动排；本周剩余容量不够的条目留在待安排池，不硬塞某一天」。周文档末尾会写「本周还剩 N 条排在待安排池」，现场可指。
- ❌ 「大纲就是一堆章节名」→ ✅ 每个阶段都有「交付物 + 过关标准」（可验收），点开计划文档能看到。
- ❌ 「再排一次本周会更好/更全」→ ✅ 「一周只排一次：已排过的周会直接退回，要改就在计划页拖节点，或告诉它把哪几条改到哪天」。已排过的周不会重复追加单元（旧版本曾把同一周越排越多）。
- ❌ 说「AI 自动帮你勾完成」时又不演示撤销 → ✅ 演示 `AI 自动完成` 卡的「撤销」（会改回待做并写屏蔽）。
- ❌ 「它自己就把我的计划改了」→ ✅ 「自主轮只建议：走完一个阶段/一份计划后它先给方案和选项，真正动计划是你点选后的下一轮（见 §8）」。
- ❌ 跟读助手说的周号 → ✅ 助手偶尔把「下一周」说成「这周」（W47/W46 口误），旁白统一说「下一周」。

## 6. 90 秒速览版（评审预览用）

1. 0–10s：一句话目标 + 过程行「搜索资料 → 抓取正文」。
2. 10–25s：三个阶段大纲 + 每天时长建议 + 「每天 2 小时」选择。
3. 25–45s：计划页右侧阶段进度 + 周刻度 + 展开今天 + 像素进度。
4. 45–60s：点节点看资源 → 勾掉一个 → 练习建议卡 → 单题作答。
5. 60–75s：管家自动重排的状态行 + 计划节点换日。
6. 75–90s：周复盘叙述 + 计划文档只读页 → 收束一句话。

## 7. 8 分钟答辩版增补

- 3 分钟主线同第 1 节，之后补：
  - 架构一页：内核 / 计划后端（事件溯源）/ AI 层 / 插件三轨（讲解 1 分钟）。
  - 数据与可靠性：本地 SQLite、事件可追溯、撤销、删除范围可控（清除数据）、安卓共享代码约束（1 分钟）。
  - 评测与局限：题库规模、掌握度是启发式、没有云端同步、移动端未落地（1 分钟）。
  - 后续路线：目标/能力地图、语义记忆、题源扩展（1 分钟）。

## 8. 两条 AGENT 自主链（2026-11-08 新增，主片外的加分镜头）

> 共同前提：**没有按钮**。用户只做「勾完成」这一个正常动作；管家在后台发现「刚好跨过阶段/计划的终点」才自己开口。
> 写工具在这一轮**故意不可用**——它只能建议 + 给选项，改计划发生在用户点选之后的下一轮。
> 录前按 §0 的「两条自主链的预置数据」准备；每条链录完都要从 seed 重新拷 home（触发是一次性事件）。

### 8.1 通识链：阶段完成 → 推一道练习（约 40 秒）

- 0–8s：计划页展开今天，右侧「阶段进度」停在阶段最后一格（还差 1 个节点）；旁白「这个阶段还差最后一个节点」。
- 8–15s：勾掉最后一个节点 → **画面切到左侧管家会话**（它自己出现，不是点的；停在计划页时左栏会出现未读圆点）。
  - 过程行：`read_learning_overview`（确认阶段真的跨过终点）、`recommend_exercises`（按刚学完的内容挑题）、`propose_practice`。
- 15–30s：练习建议卡（题目 + 该科掌握度）→ 点「开始练习」→ 二级页只有这一道 → 选择题直接判分 / 知识点题自评「记住了 / 没记住」。
- 30–40s：回会话，掌握度数字变了；旁白「它挑的是我没做过的题，不是随机一道」。
- 讲词：
  > 「注意它没有在我勾每一个节点时都跳出来——单节点完成它不说话。是「一个阶段真的走完了」这一刻它才开口，而且开口就给下一步，不是夸我。」

### 8.2 由点到面：计划完成 → 给下一步方案（约 60–90 秒）

- 0–8s：就业向计划页，只有一个阶段、右侧进度只差最后一格；页头有「目标 · 1」。
- 8–15s：勾掉最后一个节点（待安排池为空，`planDone` 成立）→ 切到管家会话。
- 15–45s：过程行逐条展开，这是这条链的重点画面：
  1. `recall_memory`：先看跨会话记忆里我定过的方向/偏好；
  2. `read_learning_overview` + `get_learning_plan`：这份计划做完到什么程度；
  3. `list_goals` + `read_plan_doc`：目标与验收、计划文档里的交付物；
  4. `read_knowledge_overview`：**知识网络里我已经会的东西**（旁白重点：这些默认算已掌握，所以它不会建议我再学一遍）；
  5. `search_web`：联网看这个方向现在要什么（岗位/项目/新工具）。
- 45–70s：回复给「下一步方案」：往哪个方向长、为什么（引到上面查到的证据），然后 `ask_choices` 摆出 2–3 个编号选项（例如「按这个方向建新计划」「把现有计划扩展到项目」「先补某块短板」）。
- 70–90s：点第 1 项 → **下一轮普通轮**才真正建计划（过程行出现写工具 `create_learning_plan`）→ 回计划页，新计划出现在左栏。
- 讲词：
  > 「计划做完不是终点。它会先回忆我给过的目标、再看我真正会了什么、然后联网确认这个方向现在的要求，才给方案——而且方案只是选项。真正动我计划的那一下，是我点的。」

**为什么「用户点一下确认」不是硬编码**：自主轮的工具集里**没有任何写工具**（建计划、排周、改节点、改节奏、建目标、写计划文档全摘掉了），它物理上改不了东西；`ask_choices` 是这一轮唯一能把决定权交回来的动作。用户点选后，普通会话按新的一句话（写操作带 `confirmed=true`）才执行。「先建议、后执行」是这一轮的设计边界，不是事先写死的剧本——换一份数据、换一句话，方案内容会变，但「先问再做」不变。

- 可选加演（各 5 秒）：
  - **未读**：完成节点后停在计划页别动，左栏管家会话出现未读圆点；点进去圆点消失。讲词「主动消息不打断你，也不会偷偷丢掉」。
  - **通知**：勾完之后立刻把窗口切到后台（这轮在后台跑完才产出建议），系统通知弹出。讲词「只有你不在看、而且它确实有话要说时，才弹系统通知」。
  - **rest 静默**：单节点完成（没跨阶段）——什么都不发生，会话里没有新消息。这是**正确行为**，别当成没触发；可以主动演一次给评审看。
