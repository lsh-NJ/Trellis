> 在此之前，项目始终缺乏价值感
> 但我始终坚信我们走在教育的最前沿方向，强过助教，强过替代老师，强过路径规划，我都要忘了我想做的是一个自我学习成长的核心出装

1. 插件化 AGENT 和计划需要融合，插件化是自由度，AGENT 是自动化  
痛点：计划维护麻烦，可能点那么一下，做那么一下总结就是一个做计划的巨大门槛  
**「让计划自己推进」**，把用户的计划管理成本降到最低，不需要用户点击完成，agent 来整合可以获得的信息自动核验并通过。计划的开始由 AGENT 做资源整合，通过互联网+用户共享数据来做第一步的规划，计划的后勤工作也可以由 AGENT 管理，任务延期的调整、用户的目标或需求产生了变化，需要 AI 作为旁观者为计划者施加计划执行的外力

   * AGENT 如何获取信息，如何自动核验，如何制定完成标准？
     1. 练习和考核可以是判据之一，之前觉得练习太麻烦，然后功能降级再降级，其实完全有解决方法，因为插件化自由化、开源方向平台可以整合多方练习数据、考试数据，在用户需要时进行校验，并推进计划
     2. 构建 知识库的过程也可以是判据
     3. 使用电子设备会有更多可追溯信息（已接入 ActivtyWatch）
     4. 可降级为传统时间管理与手动管理，每日向朋友聊天一样进行一日总结并完成今日的任务管理
     5. 完成标准和获取信息需要网络数据与平台整合数据（在用户同意的情况下会将数据进行收集，作为 AGENT 经验），越用越牛逼，越用越懂你
   * 链接日历进行更加智慧的时间管理，可导入课程表，设定日程，在管理时避开这些时间，并拟合个人偏好应用户需求进行计划安排
   * 延期调整按照安排的逻辑进行，当用户有目标变化，AGENT 有能力对所有计划进行动态调整


2. 把软件当做一个学习终端，构建知识库体系，用户通过完成学科任务（计划）或笔记点亮知识体系图节点，未来的教育中学生不应该是一块硬盘，而是能够通过善用信息体系能解决问题的创造者

  * 笔记可以只记重要名词概念，AGENT 将协助纠错补全，并将多个知识点串联，快速构建知识体系
    知识体系也是项目的核心

3. 把目标转成能力地图，从学习到实际问题，从实际问题到基础能力学习
   当我的能力足以做到某一件事，AGENT 来构建问题验证、内化、拓展能力
   当我想要解决某一个问题，AGENT 将问题拆解成我需要的能力，让我来一步步解决问题
   我有基础语言能力， 我会基础检索，这时 AGENT 可以推荐我完成一个可上线的 RAG 应用，同时学习更多有价值的东西，我懂点基础，但我该怎么让这些知识具有生产力？我还缺点检索评估、融合检索能力，但我有基础能很快上手，进行更高一点的项目也能拓展知识
   当我先要做一个零代码应用构建系统，AGENT 同样可以拆解问题需要
   当我刚学了一种知识，AGENT 能提出问题

>相信 AI 的能力，做不到只有两种原因：数据不够、prompt（skill） 没写好
