# 会话页面：把「它在想什么」和「它说了什么」分开

> 依据 `trellis-review/会话设计.md`（2026-10-24）实现。设计稿在 `trellis-review/conversation.html`。

## 问题

旧聊天页里，agent 的执行轨迹（判断 / 第 N 步 / 工具入参）和它的答复同字号、同颜色、同左边距。
读者必须逐行读完才知道哪一句是结论；一轮跑十步时，屏幕上九成文字是过程，结论被埋在中间。

## 五层信息

| 层 | 内容 | 呈现 |
|---|---|---|
| L1 | 用户输入 | 右对齐，`primaryContainer` 青柠底墨字，14.5px，圆角 10/10/3/10 |
| L2 | 结论 | 左对齐 15.5px / 行高 27.6sp / 最宽 34em（约 34 个汉字） |
| L3 | 过程摘要 | 一行「过程 · N 个动作 · 改动 M 处  list_cards → arrange_cards」，点开才看细节 |
| L4 | 过程细节 | 等宽小字 12sp（工具结果 11sp、灰 75%），机器语法只允许出现在这一层 |
| L5 | 元信息 | `时间 · N 步 · 耗时`，以及「撤销这次改动 / 看差异 / 复制」 |

过程行默认折叠：运行中、失败时自动展开（失败不展开等于让人猜），正常结束默认收起。

## 三种状态

- **完成**：Trellis + 状态点 + 「完成」+ 耗时；结论正文；动作条。
- **运行中**：状态点换成琥珀色 + 11dp 转圈 + 「停止生成」；过程自动展开；结论区先显示「…」。
  流式文本照常往结论区里长，长完替换成最终答复。
- **没做成**：状态点红；过程自动展开；结论区下面是失败块——
  「这一轮没做成 / 卡在哪一步 / 为什么 / 数据动没动」。
  数据动过就提示可以撤销，没动就明说没动。

## 三个动作（解决「它改了我的界面」）

- **撤销这次改动**：每轮开始前对宿主状态拍快照（`cardLayout` / `uiPrefs` / `pluginCardStyles`），
  结束后写成一句「布局改了 1 处：slot.home.section」这样的可读差异；撤销只回退宿主状态，
  不碰插件数据，也不去反向调用 `arrange_cards`（反向调用可能改到别的东西）。
  快照只在内存里：重启后的旧轮次不能撤销，按钮上直接写明这一点，不假装能撤。
- **看差异**：展开这一轮到底改了哪几处，逐行列出。
- **复制**：复制结论正文（过程不复制）。

## 会话列表

- 按「今天 / 昨天 / 更早」分组，选中项左侧 2dp 主色竖条 + 青柠底；
- 副标题 `时间 · N 轮`；
- 悬停出现 `⋯` 菜单 → 删除；删除要二次确认，文案说明「从磁盘删掉，不能恢复」；
- 运行中不能切段、不能删（切走会让用户以为跑完了）。

## 输入条

- 页面 chip（「当前页 · 对话」，青柠底强调色文字）+ 三条示例提示，点一下填进输入框；
- `Enter` 发送、`Shift+Enter` 换行、`↑` 召回上一条、`Esc` 停止、`Ctrl+K` 聚焦；
- 运行中仍可打字，发送会提示「还在跑」而不是丢掉输入；
- 未配置 key 时只显示配置指引（两行，不铺满屏幕）。

## 边界

- 对话记录存在 `<home>/chat/<id>.json`；坏文件、带 BOM 的文件跳过单条，不让整张列表消失。
- 打开旧会话时只把最近 20 条正式发言接回模型上下文；过程行不喂给模型。
